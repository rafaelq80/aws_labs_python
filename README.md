Este repositório reúne os exercícios práticos desenvolvidos ao longo dos laboratórios de Python do programa **AWS ReStart**, uma iniciativa da Amazon Web Services voltada para a capacitação de profissionais em computação em nuvem e desenvolvimento de software.

Os laboratórios cobrem desde os fundamentos da linguagem Python até tópicos mais avançados, como manipulação de arquivos, depuração de código, automação de sistemas e conceitos introdutórios de DevOps — construindo progressivamente as habilidades necessárias para atuar em ambientes de tecnologia modernos.

## Requisitos

- Python 3.x

```bash
pip install tabulate
```

------

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

1. Acesse a pasta do laboratório desejado:

```bash
cd lab_108
```

1. Execute o script:

```bash
python script.py
```

## Sobre o AWS ReStart

O [AWS ReStart](https://aws.amazon.com/pt/training/restart/) é um programa de treinamento imersivo e gratuito que prepara candidatos para carreiras na área de tecnologia da informação, com foco em computação em nuvem. O programa combina conteúdo teórico, laboratórios práticos e suporte ao desenvolvimento de carreira.
